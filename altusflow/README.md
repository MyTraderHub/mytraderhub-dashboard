# AltusFlow.ai

Landing page, chatbot, and sales docs for **AltusFlow.ai**.

## Files in this folder

| File | What it is |
|------|------------|
| `index.html` | Landing page — open in browser |
| `chatbot.js` | AI chat assistant |
| `docs/sales/` | ICP guidelines + sales strategy |
| `docs/prompts/` | Lead sourcing agent prompt |

## Preview

```bash
cd altusflow
python3 -m http.server 8080
```

Open: http://localhost:8080/index.html
